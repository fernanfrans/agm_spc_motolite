# AGM | AEC-L14 Compression Web Application

## SPC Chart - Compression Monitoring

This repository contains the Statistical Process Control (SPC) application for AGM compression monitoring.

### Purpose

- Track and monitor compression data for AGM AEC-L14 processes
- Generate SPC charts for real-time process control
- Identify out-of-control conditions and process variation

### Features

- SPC Chart visualization
- Compression monitoring dashboard
- Control limit calculations
- Process capability analysis
- Data-driven decision making
